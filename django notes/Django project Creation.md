
## 1. Virtual Environment
---Project-inu separate Python environment create cheyyan.

python -m venv env

## 2. Activate Environment

env\Scripts\activate

----(env) varumbol environment active aanu.

## 3. Install Django

pip install django

## 4. Create Project

django-admin startproject filmatography

----startproject → new Django project create cheyyan.

## 5. Enter Project

cd filmatography

## 6. Create App

python manage.py startapp movie

startapp → project-inullil new app create cheyyan.

## 7. Run Server

python manage.py runserver

## Browser:

http://127.0.0.1:8000/
Important Difference
startproject → Django project create
startapp     → Django app create
runserver    → Django server run

## Basic Flow:

venv → install Django → startproject → startapp → runserver_
